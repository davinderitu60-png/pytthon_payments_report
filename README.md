
# Python Payment Report Generator

## About the Project

This is a beginner Python project that reads customer
payment data from a CSV file and generates a payment report.

## Features

- Reads payment data from a CSV file.
- Cleans customer names.
- Calculates total payments.
- Counts the number of payments.
- Finds the largest and smallest payments.
- Calculates average payments.
- Counts payments reaching or falling below KSh 1,000.
- Saves the report to a text file.

## Technologies Used

- Python
- CSV
- File handling
- Loops
- Conditional statements

## Project Files

- `read_payments.py` - Main Python program.
- `payments.csv` - Sample customer payment data.
- `payment_summary.txt` - Automatically generated report.

## How to Run

1. Install Python.
2. Open this folder in VS Code.
3. Open the terminal in VS Code.
4. Run the command:

   `python read_payments.py`

5. Open `payment_summary.txt` to view the report.

## Sample Results
